### 1. 拉取分支

```bash
cd RL_for_nav
git fetch origin
git checkout claude/hierarchical-sac-mppi
```

### 2. 训练（Plan B v4.1）

在 `RL_car/src/nav_demo/scripts/beam_map/` 目录下运行：

```bash
# 使用 guided profile（Plan B 分解 reward）
python train_hierarchical_sac_mppi_v41.py \
  --reward-profile guided \
  --total-timesteps 300000 \
  --seed 0 \
  --frame-stack 4 \
  --eval-freq 5000 \
  --n-eval-episodes 5 \
  --checkpoint-freq 50000

# 断点续训
python train_hierarchical_sac_mppi_v41.py \
  --reward-profile guided \
  --load-model ./training_hierarchical_mppi_v41_guided_results/final_model_hierarchical_v41_guided \
  --total-timesteps 500000
```

### 3. 对比评测

训练完成后，对比 Plan B vs 纯 SAC vs 纯 MPPI：

```bash
python compare_sac_mppi.py \
  --model ./training_hierarchical_mppi_v41_guided_results/best_model \
  --modes baseline sac_mppi hierarchical_mppi_v41_guided \
  --episodes 20 \
  --seed 42
```

### 4. TensorBoard 监控

```bash
tensorboard --logdir ./sac_hierarchical_mppi_v41_guided_log/
```

重点看这几个指标：
- `rollout/ep_rew_mean` — episode reward 曲线
- `mppi_correction_bonus` — MPPI 修正贡献（应该 >0）
- `mppi_consistency_penalty` — SAC-MPPI 一致性（应该随训练下降）
- `mppi_delta_norm` — 平均修正幅度

### 5. 如果只想测 compat 模式（无 reward 分解，仅共享代价函数 + delta 感知）

```bash
python train_hierarchical_sac_mppi_v41.py \
  --reward-profile compat \
  --total-timesteps 300000
```

这样可以用 `compat` 和 `guided` 两个 profile 做 ablation：`compat` 只有共享代价 + delta 感知，`guided` 在此基础上多了 reward 分解。
