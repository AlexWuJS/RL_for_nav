# 脚本运行说明

本文档整理项目中常用、重要、可直接运行的脚本。以后新增重要运行入口时，需要同步更新本文档。

默认工作目录：

```bash
cd ~/RL_car/RL_car/src/nav_demo/scripts/beam_map
```

如需从仓库根目录运行测试：

```bash
cd ~/RL_car/RL_car
```

## 训练脚本

### `train.py`

纯 SAC baseline 训练入口，使用 `MyCarEnv`、`LidarProcessor`、4 帧堆叠，默认保存到：

```text
./training_usv_v2_results/
```

运行：

```bash
python train.py
```

### `train_hierarchical_sac_mppi.py`

第一版层级 SAC-MPPI 训练入口。SAC 输出 4 维 intent，MPPI 每步生成底层 `[surge, yaw]`。该版本主要用于历史对比。

运行示例：

```bash
python train_hierarchical_sac_mppi.py \
  --total-timesteps 50000
```

### `train_hierarchical_sac_mppi_v2.py`

触发式层级 SAC-MPPI v2 训练入口。SAC intent 默认映射为 prior action，MPPI 只在风险触发时尝试修正；支持继续训练和 delta penalty consistency 实验。

短训练：

```bash
python train_hierarchical_sac_mppi_v2.py \
  --total-timesteps 50000
```

开启 consistency / delta penalty：

```bash
python train_hierarchical_sac_mppi_v2.py \
  --enable-delta-penalty \
  --delta-penalty-alpha 0.08 \
  --delta-deadband 0.10 \
  --save-dir ./training_hierarchical_mppi_v2_consistency_results/ \
  --log-dir ./logs_hierarchical_mppi_v2_consistency/ \
  --total-timesteps 50000
```

继续训练到指定总步数：

```bash
python train_hierarchical_sac_mppi_v2.py \
  --load-model ./training_hierarchical_mppi_v2_results/best_model \
  --total-timesteps 120000
```

### `train_hierarchical_sac_mppi_v3.py`

Frenet 子目标层级 SAC-MPPI v3 训练入口。SAC 输出长期导航意图：

```text
progress_intent
lateral_offset_intent
caution_intent
recovery_intent
```

MPPI 围绕 Frenet 局部子目标执行短期轨迹优化，默认保存到：

```text
./training_hierarchical_mppi_v3_results/
./logs_hierarchical_mppi_v3/
```

运行：

```bash
python train_hierarchical_sac_mppi_v3.py \
  --total-timesteps 50000
```

正式训练示例：

```bash
python train_hierarchical_sac_mppi_v3.py \
  --total-timesteps 300000
```

继续训练：

```bash
python train_hierarchical_sac_mppi_v3.py \
  --load-model ./training_hierarchical_mppi_v3_results/best_model \
  --total-timesteps 120000
```

### `train_hierarchical_sac_mppi_v4.py`

半离散层级 SAC-MPPI v4 训练入口。高层策略输出：

```text
6 个 mode score:
cruise
cautious_cruise
avoid_left
avoid_right
recover_center
brake

2 个连续参数:
speed_scale
avoid_strength
```

底层仍保持连续 `[surge, yaw]` 控制，但 MPPI 只作为触发式局部修正器工作。脚本支持两套奖励配置：

- `compat`：尽量与旧主线奖励对齐，主要用于保持和 baseline 的结构可比性。
- `enhanced`：在 compat 基础上加入 mode switch penalty、recover bonus、hazard mode bonus 等增强项。

默认保存目录：

```text
compat:
./training_hierarchical_mppi_v4_compat_results/
./logs_hierarchical_mppi_v4_compat/

enhanced:
./training_hierarchical_mppi_v4_enhanced_results/
./logs_hierarchical_mppi_v4_enhanced/
```

compat 短训练：

```bash
python train_hierarchical_sac_mppi_v4.py \
  --reward-profile compat \
  --total-timesteps 50000
```

enhanced 正式训练示例：

```bash
python train_hierarchical_sac_mppi_v4.py \
  --reward-profile enhanced \
  --total-timesteps 300000
```

继续训练 compat：

```bash
python train_hierarchical_sac_mppi_v4.py \
  --reward-profile compat \
  --load-model ./training_hierarchical_mppi_v4_compat_results/best_model \
  --total-timesteps 120000
```

继续训练 enhanced：

```bash
python train_hierarchical_sac_mppi_v4.py \
  --reward-profile enhanced \
  --load-model ./training_hierarchical_mppi_v4_enhanced_results/best_model \
  --total-timesteps 120000
```

## 评估与对比脚本

### `compare_sac_mppi.py`

离线对比评估入口，用同一批 episode seed 对比不同控制模式，并输出 CSV、summary JSON 和可选图表。

常用模式：

```text
baseline
shield_only
shield_first
shield_mppi_teacher
shield_mppi_execute
hierarchical_mppi
hierarchical_mppi_v2
hierarchical_mppi_v2_consistency
hierarchical_mppi_v3
hierarchical_mppi_v4_compat
hierarchical_mppi_v4_enhanced
hierarchical_ablation
hierarchical_ablation_v2
hierarchical_ablation_v2_consistency
hierarchical_ablation_v3
hierarchical_ablation_v4
```

v3 对比：

```bash
python compare_sac_mppi.py \
  --mode hierarchical_ablation_v3 \
  --baseline-model ./training_usv_v2_results/best_model \
  --hierarchical-v2-model ./training_hierarchical_mppi_v2_results/best_model \
  --hierarchical-v3-model ./training_hierarchical_mppi_v3_results/best_model \
  --episode 30 \
  --output-dir ./comparison_results_hierarchical_mppi_v3 \
  --plot
```

v2 consistency 对比：

```bash
python compare_sac_mppi.py \
  --mode hierarchical_ablation_v2_consistency \
  --baseline-model ./training_usv_v2_results/best_model \
  --hierarchical-v2-model ./training_hierarchical_mppi_v2_consistency_results/best_model \
  --episode 30 \
  --output-dir ./comparison_results_hierarchical_mppi_v2_consistency \
  --plot
```

v4 compat / enhanced 对比：

```bash
python compare_sac_mppi.py \
  --mode hierarchical_ablation_v4 \
  --baseline-model ./training_usv_v2_results/best_model \
  --hierarchical-v4-compat-model ./training_hierarchical_mppi_v4_compat_results/best_model \
  --hierarchical-v4-enhanced-model ./training_hierarchical_mppi_v4_enhanced_results/best_model \
  --episode 30 \
  --output-dir ./comparison_results_hierarchical_mppi_v4 \
  --plot
```

只评估 v4 compat：

```bash
python compare_sac_mppi.py \
  --mode hierarchical_mppi_v4_compat \
  --hierarchical-v4-compat-model ./training_hierarchical_mppi_v4_compat_results/best_model \
  --episode 30 \
  --output-dir ./comparison_results_hierarchical_mppi_v4_compat \
  --plot
```

只评估 v4 enhanced：

```bash
python compare_sac_mppi.py \
  --mode hierarchical_mppi_v4_enhanced \
  --hierarchical-v4-enhanced-model ./training_hierarchical_mppi_v4_enhanced_results/best_model \
  --episode 30 \
  --output-dir ./comparison_results_hierarchical_mppi_v4_enhanced \
  --plot
```

低干预 safety layer 消融：

```bash
python compare_sac_mppi.py \
  --model ./training_usv_v2_results/best_model \
  --mode ablation \
  --episode 30 \
  --output-dir ./comparison_results_low_intervention \
  --plot
```

### `plot_comparison_curves.py`

读取 `compare_sac_mppi.py` 输出的结果目录，单独重新生成图表。通常 `compare_sac_mppi.py --plot` 会自动调用它。

运行：

```bash
python plot_comparison_curves.py \
  --result-dir ./comparison_results_hierarchical_mppi_v3 \
  --output-dir ./comparison_results_hierarchical_mppi_v3/plots \
  --max-steps 180
```

v4 对比结果重绘：

```bash
python plot_comparison_curves.py \
  --result-dir ./comparison_results_hierarchical_mppi_v4 \
  --output-dir ./comparison_results_hierarchical_mppi_v4/plots \
  --max-steps 180
```

当前 `v4` 图表会额外输出：

- `v4_mode_usage.png`
- `action_source_stack.png`

其中会统计：

- mode occupancy
- mode switch frequency

## Gazebo / ROS 可视化测试脚本

### `test01.py`

Gazebo 仿真可视化运行入口。加载训练好的 SAC 模型，并可选择 baseline、shield、层级 MPPI 模式。

纯 SAC：

```bash
python test01.py \
  --mode baseline \
  --model ./training_usv_v2_results/best_model
```

shield-only 安全兜底：

```bash
python test01.py \
  --mode shield_only \
  --model ./training_usv_v2_results/best_model
```

层级 v2：

```bash
python test01.py \
  --mode hierarchical_mppi_v2 \
  --model ./training_hierarchical_mppi_v2_results/best_model
```

层级 v3：

```bash
python test01.py \
  --mode hierarchical_mppi_v3 \
  --model ./training_hierarchical_mppi_v3_results/best_model
```

层级 v4 compat：

```bash
python test01.py \
  --mode hierarchical_mppi_v4_compat \
  --model ./training_hierarchical_mppi_v4_compat_results/best_model
```

层级 v4 enhanced：

```bash
python test01.py \
  --mode hierarchical_mppi_v4_enhanced \
  --model ./training_hierarchical_mppi_v4_enhanced_results/best_model
```

### `start_rviz.py`

启动 RViz 辅助脚本，用于观察仿真环境和传感器数据。

运行：

```bash
python start_rviz.py
```

## 验证与绘图辅助脚本

### `verify_train.py`

小规模 SAC 训练验证脚本，用于确认环境、SB3、reward、训练循环是否能正常工作。不用于正式结果。

运行：

```bash
python verify_train.py
```

### `plot_resultes.py`

读取 TensorBoard event 日志并绘制训练曲线，默认读取 `./sac_car_log/`。如果使用新的 log 目录，需要在脚本中调整 `log_directory`。

运行：

```bash
python plot_resultes.py
```
